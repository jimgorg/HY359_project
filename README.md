# Pet Sitting and Booking Web Application

#### A university Web Development project build with Java Servlets, MySQL and javascript. The applications is a reservation platform for pet sitting, consisted of pet owners, pet keepers and the administator.
 
## Project Status

#### This repository preserves an academic web project created in 2023. The project has been recently build successfully and run locally on Apatche Tomcat 9. The database connectivity and end-to-end workflows have not been fully tested in the current enviroment.

## Features

### Pet Owners

- Register an account and update profile information.
- Register pets and browse pet keepers.
- Submit pet accommodation booking requests.
- Exchange messages with a keeper during an active booking.
- Mark bookings as completed and submit reviews. 

### Pet Keepers
- Register an account and update profile information.
- View pending booking requests and accept or reject them.
- Exchange messages with pet owners during active bookings.
- View reviews and statistics for completed bookings.
  
### Administrator

- View registered owners and keepers.
- Delete users.
- View application statistics.

## Requirements

- AJDK and Maven compatible with the compiler settings in pom.xml.
- Apache Tomcat 9.
- A MySQL database.
